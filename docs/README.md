# Docs

These are the working notes from the build, published as they were rather than tidied into a manual. They were written during the project, so a few things to know:

- **Paths:** they refer to `v2/` (now [`../generator/`](../generator/)), `fork/` (now [`../plugin/`](../plugin/)) and `claude/LR-Console-*.md` (now this folder). Session logs and handovers they mention are not included.
- **Markers:** **[M]** measured on the board, **[S]** read from source, **[I]** inferred, **[?]** assumed, **[stated]** my own call or report. Trust them in that order.
- **CJ** is me.
