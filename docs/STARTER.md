# Two-module starter: one EN16 + one VSN1

A cut-down LR Console for people who don't want to buy six modules. It was written in answer to a question on Reddit, not because I use it.

> **Status: not tested on hardware.** My board is the six-module one and I have not taken it apart to try this. The profiles are generated by the same toolchain, pass the same build checks (longest event 795 of 908 characters), and pass a stub test in a Lua interpreter (`generator/test_starter.py`). That proves the code parses and the logic follows the source. It does not prove what real modules do. If you try it, please open an issue and say what happened, working or not.

## What you get

**VSN1** (the one with the screen, plugged into the computer):

- Eight keys choose a slider; the jog wheel turns it. The screen shows the slider's name and the value Lightroom reports back.
- Jog gestures, the same as on the big board: turn = adjust, hold and turn = fine, tap = back to where this turn started, hold 0.6 s without turning = Adobe's default.
- The four small buttons switch page.
- When Lightroom enters Masking, pages 1 and 2 switch to the mask versions of the same sliders by themselves. In Crop, the jog straightens.
- Slider follow: move a slider with the mouse and the board selects it, if it is on the current page.

| Page | Keys 1–4 (top row) | Keys 5–8 (bottom row) |
|---|---|---|
| 1 Basic | Temp, Tint, Exposure, Contrast | Highlights, Shadows, Whites, Blacks |
| 2 Presence | Texture, Clarity, Dehaze, Vibrance (mask: Hue) | Saturation, Vignette, Sharpening, Noise Reduction |
| 3 Tone | Curve Highlights, Lights, Darks, Shadows | Colour Grading Shadow / Midtone / Highlight luminance, Balance |
| 4 Actions | Previous, Next, Reject, Pick | Undo, Redo, Crop on/off, Masking on/off |

Page 4's keys act directly. Nothing is selected there, so the jog does nothing on page 4 except straighten in Crop.

**EN16** (same on every page): the Colour Mixer for four colours.

| | Knob 1 | Knob 2 | Knob 3 | Knob 4 |
|---|---|---|---|---|
| Row 1 | Red Hue | Red Saturation | Red Luminance | Split-tone preset: Teal/orange |
| Row 2 | Orange … | | | Warm/violet |
| Row 3 | Yellow … | | | Green/magenta |
| Row 4 | Green … | | | Amber |

Press an HSL knob to reset it; hold and turn for fine steps. Press a preset knob to apply the preset, turn it to scale its strength; its name shows on the VSN1 screen.

## What you lose against the six-module board

- Eight sliders a page, not sixteen, and no second screen.
- Only Red, Orange, Yellow and Green on the mixer. Aqua, Blue, Purple and Magenta live on the second EN16 on my board. `lr_pages.en16('EN16-B')` builds them if you'd rather have those, or have two EN16s.
- No zoom dials, star ratings, colour labels, copy/paste settings, or before/after key. Those are on TEK2 and BU16.
- No keyboard-shortcut keys, so the Hammerspoon script isn't needed.

## Install

1. Install the plugin fork as in the [main README](../README.md#quick-start). The starter needs the fork, not the stock Intech plugin. Restart Lightroom.
2. Copy `configs/starter-en16-vsn1/*.json` into `~/Documents/grid-userdata/configs/`.
3. In Grid Editor, with both modules connected: on page 1, select the VSN1, Clear, load `Starter Page 1 VSN1`, Store. Select the EN16, Clear, load `Starter EN16 HSL`, Store. Repeat for pages 2 to 4 with the matching VSN1 profile and the same EN16 profile each time.
4. Read the code back off the module to check it took.

The two modules can sit either side of each other. The code doesn't use module positions.

## Things I had to assume

Check these first if it misbehaves.

1. **EN16 element order.** With the EN16 the way up Grid Editor draws it, I assume knob 0 is top-left and numbering runs left to right, row by row. Test: with a colour photo open in Develop, the **top-left knob should move Red Hue**. If it moves something else, your EN16 is rotated relative to my assumption. For a quarter-turn anticlockwise (how mine are mounted, and measured there), set `EN16_ROT = 270` in `lr_starter.py` and rebuild.
2. **VSN1 Left.** The profiles are built from the VSN1L Default export. Grid Editor may refuse them on a VSN1R. If so, export a Default config from your own module, add it to `generator/templates/` and `lr_pages.EXPORTS`, and change `'VSN1L'` in `lr_starter.vsn1()`.
3. **How VSN1 tells its own keys from the EN16.** On my board a module's own events arrive with source offset 127, 127 (measured). The starter treats anything else as the EN16. A third module on the bus would be mistaken for it.
4. **Mac.** Like the rest of the project, tested only on macOS. Nothing in the starter is Mac-specific that I know of.

## Rebuilding

```
cd generator
python3 build_all.py out 1120-1510 flipped lr_starter   # reproduces configs/starter-en16-vsn1
pip install lupa && python3 test_starter.py out          # the stub test
```

To change which sliders are on which key, edit the `P1_*` to `P4_*` lists in `lr_starter.py`. Parameter names are Adobe's `LrDevelopController` names; mask versions are `local_<Name>`.
